## Figures 2–3: image agreement versus sample description

Exact image agreement does **not** resolve the manuscript's sample-description discrepancy. The source figures use the full 17,336-debate frame with zero-filled scores for unannotated rows; the paper describes 8,401 reply dyads. There are 8,286 scored dyads after cleaning. The default run reproduces the actual figures, and a separately named sensitivity file reports the conditional 8,286-dyad analysis. See [Known differences](KNOWN_DIFFERENCES.md).
